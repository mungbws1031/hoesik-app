# Phase 2 — 18개+ 원석 아이디어 생성

**주제:** $ARGUMENTS

Phase 1 리서치 결과(또는 대화 맥락의 인사이트)를 바탕으로 6가지 방법론에서 각 최소 3개씩 아이디어를 생성해.
**총 18개 미만이면 완료하지 말 것.**

---

## 방법론 1: SCAMPER (7개)

각 글자마다 1개씩 아이디어 도출:

- **S**ubstitute — 기존 재료·프로세스를 다른 것으로 대체하면?
- **C**ombine — 두 기능·제품을 합치면?
- **A**dapt — 다른 산업의 솔루션을 가져오면?
- **M**odify/Magnify — 특정 속성을 극단적으로 키우거나 줄이면?
- **P**ut to other uses — 현재 제품을 전혀 다른 용도로 쓰면?
- **E**liminate — 핵심 단계를 없애면?
- **R**everse/Rearrange — 순서나 방향을 뒤집으면?

## 방법론 2: HMW (How Might We) (3개)

형식: "우리는 어떻게 하면 [페인포인트]를 [유저]를 위해 해결할 수 있을까?"
→ 질문 3개 작성 후 각 질문에 아이디어 1개 이상 도출

## 방법론 3: JTBD (Jobs-to-be-Done) (3개)

유저가 진짜 고용하고 싶은 것:
- **Functional Job:** 실제 해야 할 일 → 아이디어 1개
- **Emotional Job:** 느끼고 싶은 감정 → 아이디어 1개
- **Social Job:** 남에게 보이고 싶은 모습 → 아이디어 1개

## 방법론 4: 아날로지 (Analogy Thinking) (3개)

전혀 다른 3개 산업에서 작동하는 솔루션을 가져와:
"[산업]에서는 이 문제를 [방법]으로 풀었다 → 우리 제품에 적용하면 [아이디어]"
권장 산업: 항공, 요식업, 게임, 의료기기, 군사, 건설, 패션 중 3개 선택

## 방법론 5: 극단적 유저 (Extreme User) (3개)

- **파워 유저:** 가장 열정적이고 헤비한 사용자라면 무엇을 원할까?
- **비사용자(Reluctant User):** 절대 안 쓰려는 사람이 쓰게 만들려면?
- **접근성 유저:** 시각/인지/신체 제약이 있는 사용자라면?

## 방법론 6: 미래 역산 (Backcasting from 2030) (3개)

"2030년에 이 문제가 완벽하게 해결된 세계를 상상해. 그 세계에서 역산하면 지금 무엇을 해야 하나?"
→ 미래 상태 1문장 + 현재 시작점 아이디어 1개씩, 3세트

## 실행 규칙
- 모든 출력은 **한국어**
- 반드시 18개 이상 생성 — 부족하면 방법론 추가 반복
- 각 아이디어는 구체적으로 (추상적인 "개선" 금지, 메커니즘 명시)
- SuGenTech 브랜드 컨텍스트 반영: TRF 기술, 4-호르몬, IVDR, SU Red
- Phase 2 결과는 `./ideation_output/generate_<날짜>_<슬러그>.md`에 저장
