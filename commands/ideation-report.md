# Phase 3–5 — 점수화 · 구체화 · 저장

**주제:** $ARGUMENTS

> **인수가 없을 경우:** `$ARGUMENTS`가 비어 있으면 대화 맥락에서 가장 최근에 실행된
> `/ideation-generate` 또는 `/ideation-research`의 주제를 자동으로 사용해.
> 주제를 특정할 수 없으면 "주제를 인수로 입력해 주세요. 예: `/ideation-report 주제명`" 라고 안내해.

대화 맥락의 Phase 2 아이디어 목록을 가져와 Phase 3 → 4 → 5를 순서대로 실행해.

---

## Phase 3 — 가중치 매트릭스 점수화 → TOP 5 선별

### 채점 기준 (각 1–5점)

| 기준 | 가중치 | 판단 기준 |
|---|---|---|
| 시장 임팩트 | **30%** | 타겟 시장 크기 × 해결 강도 (페인포인트 해소 정도) |
| 구현 실현성 | **25%** | 기술적·재정적 실현 가능성 (현재 기준, 1년 내 MVP 가능하면 5점) |
| IVDR/규제 용이성 | **20%** | Class A = 5점, Class B = 3점, Class C = 1점 |
| 차별성 | **15%** | 경쟁사 전무 = 5점, 개선 수준 = 3점, 유사 존재 = 1점 |
| SuGenTech 전략 부합 | **10%** | TRF·4-호르몬·슈얼리 오브제 로드맵과 정합성 |

**가중 총점 = Σ(점수 × 가중치)**
동점 시 차별성 점수 → 구현 실현성 점수 순으로 우선

### 출력 형식

```
### Phase 3 결과 — 점수 매트릭스 (전체 아이디어)

| # | 아이디어 | 임팩트(×0.30) | 실현성(×0.25) | 규제(×0.20) | 차별성(×0.15) | 전략(×0.10) | 총점 | 근거 |
|---|---|---|---|---|---|---|---|---|
| 1 | ... | 점수×0.30 | 점수×0.25 | ... | ... | ... | **X.XX** | 한 줄 근거 |

### TOP 5 선정
| 순위 | 아이디어 | 총점 | 선정 이유 |
|---|---|---|---|
| 🥇 1위 | ... | X.XX | ... |
| 🥈 2위 | ... | X.XX | ... |
| 🥉 3위 | ... | X.XX | ... |
| 4위 | ... | X.XX | ... |
| 5위 | ... | X.XX | ... |
```

## Phase 4 — TOP 5 구체화

TOP 5 각각에 대해 아래 템플릿으로 상세 기술:

```
### 아이디어 [순위]: [제목]

**타겟 유저**
- 나이·상황: ...
- 핵심 동기: ...
- 페인포인트: ...

**핵심 기능 3가지**
1. [기능명]: [메커니즘 설명]
2. [기능명]: [메커니즘 설명]
3. [기능명]: [메커니즘 설명]

**차별점**
경쟁사 [이름]은 [약점]. 슈얼리 오브제는 [차별화 요소]로 [결과].

**IVDR 규제 체크**
- 기기 분류: Class A / B / C (근거: IVDR Rule [번호])
- 필요 인증: CE [Class], FDA [경로], ISO [번호]
- 주요 리스크: ...
- 완화 방안: ...

**구현 난이도:** ★☆☆☆☆ ~ ★★★★★ ([이유])

**MVP 첫 스텝**
3개월 안에 할 수 있는 가장 작은 실험:
→ [구체적 행동 1가지, 담당자·예산·성공 기준 포함]
```

## Phase 5 — 로컬 저장 + 최종 보고

### 저장 규칙

1. Phase 3–4 전체 결과를 아래 경로에 저장:
   ```
   ./ideation_output/YYYYMMDD_<슬러그>.md
   ```
   - 날짜: 오늘 날짜 ISO 형식 (예: 20260227)
   - 슬러그: 주제 영문 변환, 영문/숫자/하이픈만 (예: `urine-collection-dipping`)
   - 파일 없으면 디렉토리 생성 후 저장
   - 저장 내용: Phase 1~4 전체 마크다운 (요약본 아님)

2. 저장 완료 후 최종 요약 출력:

```
## 최종 보고

| 항목 | 내용 |
|---|---|
| 주제 | $ARGUMENTS |
| 실행일 | YYYY-MM-DD |
| 총 생성 아이디어 | N개 |
| 채점 방법 | 가중 매트릭스 (임팩트30%/실현성25%/규제20%/차별성15%/전략10%) |
| 최고 점수 | [아이디어명] X.XX점 |
| 저장 위치 | ./ideation_output/YYYYMMDD_<슬러그>.md |
| 다음 권장 액션 | [TOP 1 기준 즉시 할 수 있는 한 가지 행동] |
```

---

## 실행 규칙
- 모든 출력은 **한국어** (코드·수식·파일명 제외)
- 점수에 반드시 근거 한 줄 명시 (숫자만 나열 금지)
- IVDR 분류 시 Rule 번호 반드시 포함
- MVP 스텝은 추상적 표현 금지 ("검토한다" X → "3D 프린팅 업체 A에 RFQ 발송" O)
- 저장 파일은 완전한 Phase 1–4 내용 포함 (요약 버전 금지)
