# 5-Phase 구조화 아이디어 발굴 엔진

**주제:** $ARGUMENTS

아래 5개 Phase를 순서대로 실행하고, 각 Phase 결과를 마크다운 섹션으로 출력해.
마지막에 전체 결과를 `./ideation_output/YYYYMMDD_<주제슬러그>.md` 파일로 저장해.

---

## Phase 1 — 웹 리서치: 현실 파악

다음 3가지를 웹 검색으로 조사해:
1. **유저 페인포인트** — "$ARGUMENTS 불편함", "pain points", "user complaints" 키워드로 검색
2. **트렌드** — 최근 12개월 내 "$ARGUMENTS" 관련 femtech / medtech / 소비자 트렌드
3. **경쟁사 갭** — 주요 경쟁 제품/서비스가 해결 못한 문제, 리뷰 평점 약점

출력 형식:
```
### Phase 1 결과
| 구분 | 핵심 인사이트 |
|---|---|
| 페인포인트 | ... |
| 트렌드 | ... |
| 경쟁사 갭 | ... |
```

## Phase 2 — 18개+ 원석 아이디어 생성 (6가지 방법론)

Phase 1 인사이트를 기반으로 각 방법론에서 최소 3개씩 아이디어를 생성해.

### 방법론 1: SCAMPER
- **S**ubstitute: 기존 재료·프로세스를 다른 것으로 대체하면?
- **C**ombine: 두 가지 기능·제품을 합치면?
- **A**dapt: 다른 산업의 솔루션을 가져오면?
- **M**odify/Magnify: 특정 속성을 극단적으로 키우거나 줄이면?
- **P**ut to other uses: 현재 제품을 전혀 다른 용도로 쓰면?
- **E**liminate: 핵심 단계를 없애면?
- **R**everse/Rearrange: 순서를 뒤집으면?

### 방법론 2: HMW (How Might We)
"우리는 어떻게 하면 [페인포인트]를 [유저]를 위해 해결할 수 있을까?"
형식으로 3개 이상 질문 생성 후 각 질문에 아이디어 도출

### 방법론 3: JTBD (Jobs-to-be-Done)
"유저가 진짜 고용하고 싶은 것은 무엇인가?"
- Functional Job: 실제 해야 할 일
- Emotional Job: 느끼고 싶은 감정
- Social Job: 남에게 보이고 싶은 모습
각 Job별 아이디어 1개 이상

### 방법론 4: 아날로지 (Analogy Thinking)
전혀 다른 3개 산업(예: 항공, 요식, 게임)에서 작동하는 솔루션을 가져와
"[다른 산업]에서는 이 문제를 이렇게 풀었다 → 우리 제품에 적용하면?"

### 방법론 5: 극단적 유저 (Extreme User)
- **파워 유저:** 가장 열정적이고 무거운 사용자라면 무엇을 원할까?
- **비사용자(Reluctant User):** 절대 안 쓰려는 사람이 쓰게 만들려면?
- **접근성 유저:** 시각/인지/신체 제약이 있는 사용자라면?

### 방법론 6: 미래 역산 (Backcasting from 2030)
"2030년에 이 문제가 완벽하게 해결된 세계를 상상해. 거기서 역산하면 지금 무엇을 해야 하나?"
3개 이상 아이디어

출력 형식:
```
### Phase 2 결과 — 원석 아이디어 목록
| # | 방법론 | 아이디어 한 줄 요약 |
|---|---|---|
| 1 | SCAMPER-S | ... |
| 2 | SCAMPER-C | ... |
...총 18개+
```

## Phase 3 — 가중치 매트릭스 점수화 → TOP 5 선별

18개+ 아이디어를 아래 5개 기준으로 각 1–5점 채점:

| 기준 | 가중치 | 설명 |
|---|---|---|
| 시장 임팩트 | 30% | 타겟 시장 크기 × 해결 강도 |
| 구현 실현성 | 25% | 기술적·재정적 실현 가능성 (현재 기준) |
| IVDR/규제 용이성 | 20% | 규제 장벽 낮을수록 고점 |
| 차별성 | 15% | 경쟁사 대비 독창성 |
| SuGenTech 전략 부합 | 10% | 브랜드·제품 로드맵과 정합성 |

**가중 총점 = Σ(점수 × 가중치)**

상위 5개를 "TOP 5"로 선정.

출력 형식:
```
### Phase 3 결과 — 점수 매트릭스 (상위 10개만 표시)
| # | 아이디어 | 임팩트 | 실현성 | 규제 | 차별성 | 전략 | 가중총점 |
|---|---|---|---|---|---|---|---|
| 1 | ... | 5×0.30 | 4×0.25 | 3×0.20 | 5×0.15 | 4×0.10 | **X.XX** |
...
### TOP 5 선정
1. [가중총점 1위] — X.XX점
...
```

## Phase 4 — TOP 5 아이디어 구체화

TOP 5 각각에 대해 아래 템플릿으로 상세 기술:

```
### 아이디어 [N]: [제목]
- **타겟 유저:** 구체적 페르소나 (나이, 상황, 동기)
- **핵심 기능 3가지:**
  1. ...
  2. ...
  3. ...
- **차별점:** 경쟁사 대비 무엇이 다른가
- **IVDR 규제 체크:**
  - 기기 분류: Class A / B / C
  - 필요 인증: CE, FDA 510k 등
  - 리스크: ...
- **구현 난이도:** ★☆☆☆☆ ~ ★★★★★
- **MVP 첫 스텝:** 3개월 안에 할 수 있는 가장 작은 실험
```

## Phase 5 — 로컬 저장 + 보고

1. 전체 Phase 1–4 결과를 `./ideation_output/YYYYMMDD_<주제슬러그>.md` 파일로 저장
   - 파일 없으면 디렉토리 생성 후 저장
   - 날짜는 오늘 날짜(ISO 형식) 사용
   - 슬러그: 주제에서 한글 제거, 영문/숫자/하이픈만 사용 (예: `urine-collection-dipping`)

2. 저장 완료 후 최종 요약 보고:
```
## 최종 요약
- 총 생성 아이디어: N개
- TOP 5 선정 기준: 가중 매트릭스 (임팩트 30% / 실현성 25% / 규제 20% / 차별성 15% / 전략 10%)
- 최고 점수 아이디어: [제목] (X.XX점)
- 저장 위치: ./ideation_output/YYYYMMDD_<슬러그>.md
- 다음 권장 액션: [TOP 1 아이디어 기준 즉시 할 수 있는 한 가지]
```

## 실행 규칙

- 모든 출력은 **한국어** (코드·수식 제외)
- 아이디어는 절대 임의로 줄이지 말 것 — Phase 2는 반드시 18개 이상
- 점수는 주관적 판단이지만 **근거를 한 줄씩** 반드시 명시
- IVDR 규제 언급 시 Class 분류 근거(Rule 번호) 포함
- 저장 파일은 Phase 1–4 전체 마크다운 포함 (요약본 아님)
