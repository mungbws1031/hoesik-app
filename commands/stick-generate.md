$ARGUMENTS 주제로 딥핑 스틱/스트립 특화 18개+ 원석 아이디어를 생성해.

> **인수가 없을 경우:** 대화 맥락에서 가장 최근 스틱 관련 주제를 자동 사용해.
> 주제를 특정할 수 없으면 "주제를 입력해 주세요. 예: `/stick-generate 정량 스틱 사용편의성`" 안내.

Phase 1 리서치 결과(또는 대화 맥락의 스틱 인사이트)를 바탕으로,
**딥핑 스틱/스트립의 소재·구조·정량 메커니즘 + 사용 편의성**에 집중해 6가지 방법론으로 생성.
**총 18개 미만이면 완료하지 말 것.**

## 방법론 1: SCAMPER (7개)
- **S**: 현재 흡수 패드 소재를 다른 소재로 대체
- **C**: 스트립 + 다른 기능(정량·밀봉·편의) 결합
- **A**: 혈당 란셋·PCR 스왑·임신 테스트기 구조 차용
- **M**: 흡수 팁 크기·두께·형태 극단 변형
- **P**: 스트립을 딥핑 외 다른 채취 방식에 사용
- **E**: 딥핑 단계 자체를 제거
- **R**: 소변↔스트립 방향을 역전

## 방법론 2: HMW (3개)
"우리는 어떻게 하면 [사용 편의성 페인포인트]를 [유저]를 위해 해결할 수 있을까?"
→ 질문 3개 + 각 질문에 스틱 구조·소재 아이디어 1개

## 방법론 3: JTBD (3개)
- Functional: 정확·빠른 채취 → 스틱 구조 아이디어
- Emotional: 위생적·깔끔한 경험 → 스틱 디자인 아이디어
- Social: 전문적 검사 자신감 → 스틱 UX 아이디어

## 방법론 4: 아날로지 (3개)
다른 산업 3개(의료기기·식품·공업)의 정량/정밀 접촉 솔루션 → 슈얼리 스트립 적용

## 방법론 5: 극단 유저 (3개)
- 파워 유저: 하루 2회 IVF 측정 여성
- 비사용자: 접촉 혐오형
- 접근성 유저: 손 떨림 고령 갱년기 여성

## 방법론 6: 미래 역산 (3개)
2030년 이상적 딥핑 스틱 상태 → 현재 시작점 아이디어

## 출력 형식
```
### Phase 2 결과 — 스틱 특화 원석 아이디어 목록 (N개)
| # | 방법론 | 아이디어 한 줄 요약 | 스틱 핵심 메커니즘 |
|---|---|---|---|
...총 18개+
```

## 실행 규칙
- 한국어 출력 (소재명·기술용어 영문 병기)
- 반드시 18개 이상 — 부족하면 방법론 추가 반복
- 각 아이디어에 물리적 메커니즘 명시 (추상 표현 금지)
- TRF 4-호르몬 분석 호환성 고려
