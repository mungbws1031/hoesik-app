# Phase 3–5 (스틱 특화) — 점수화 · 구체화 · 저장

**주제:** $ARGUMENTS

> **인수가 없을 경우:** `$ARGUMENTS`가 비어 있으면 대화 맥락에서 가장 최근에 실행된
> `/ideation-generate-stick` 또는 `/ideation-research-stick`의 주제를 자동으로 사용해.
> 주제를 특정할 수 없으면 "주제를 인수로 입력해 주세요. 예: `/ideation-report-stick 슈얼리 오브제 dipping 정량 스트립`" 라고 안내해.

대화 맥락의 Phase 2 스틱 아이디어 목록을 가져와 Phase 3 → 4 → 5를 순서대로 실행해.

---

## Phase 3 — 가중치 매트릭스 점수화 → TOP 5

### 채점 기준 (각 1–5점)

| 기준 | 가중치 | 스틱 특화 판단 기준 |
|---|---|---|
| 정량 정확도 임팩트 | **30%** | 채취 부피 CV% 개선 정도 (±5% 이내 달성 = 5점) |
| 구현 실현성 | **25%** | 기존 스트립 제조 공정 변경 없이 적용 가능하면 5점, 신규 소재 개발 필요 시 2점 |
| IVDR/규제 용이성 | **20%** | Class A = 5점, 신규 소재 ISO 10993 필요 = 3점, Class B 이상 = 1점 |
| 차별성 | **15%** | 경쟁사(Mira·Oova·Inito) 스트립 대비 구조적 독창성 |
| SuGenTech TRF 호환성 | **10%** | 4-호르몬 TRF 분석 정확도에 미치는 영향 (간섭 없음 = 5점) |

**가중 총점 = Σ(점수 × 가중치)**
동점 시: 정량 정확도 → TRF 호환성 → 구현 실현성 순으로 우선

### 출력 형식

```
### Phase 3 결과 — 스틱 아이디어 점수 매트릭스

| # | 아이디어 | 정량임팩트(×0.30) | 실현성(×0.25) | 규제(×0.20) | 차별성(×0.15) | TRF호환(×0.10) | 총점 | 핵심 근거 |
|---|---|---|---|---|---|---|---|---|
| 1 | ... | 점수×0.30 | ... | ... | ... | ... | **X.XX** | ... |

### TOP 5 선정
| 순위 | 아이디어 | 총점 | 선정 이유 |
|---|---|---|---|
| 🥇 1위 | ... | X.XX | ... |
...
```

## Phase 4 — TOP 5 스틱 아이디어 구체화

TOP 5 각각을 아래 템플릿으로 상세 기술:

```

**타겟 유저**
- 페르소나: 나이·상황·채취 빈도
- 현재 스틱 사용 시 겪는 정량 문제:
- 해결 후 기대 변화:

**스틱 구조 상세**
- 소재: [흡수 패드 소재명] / [스트립 기재 소재]
- 정량 메커니즘: [모세관/오버플로우/흡수 한계/스토퍼 중 택1] — [작동 원리 2문장]
- 목표 채취 부피: X mL ± X%
- TRF 반응 영역 보호 방식: [간섭 차단 구조 설명]

**핵심 기능 3가지**
1. [기능명]: [스틱 물리적 메커니즘 설명]
2. [기능명]: [스틱 물리적 메커니즘 설명]
3. [기능명]: [스틱 물리적 메커니즘 설명]

**경쟁사 스틱 대비 차별점**
- Mira 스트립: [약점] → 슈얼리는 [개선]
- Oova 스트립: [약점] → 슈얼리는 [개선]

**IVDR 규제 체크**
- 기기 분류: Class [A/B/C] (근거: IVDR Rule [번호])
- 신규 소재 인증: ISO 10993 생체 적합성 시험 [필요/불필요]
- 스트립 성능 검증: 분석적 민감도·특이도·재현성 데이터 필요 여부
- 기술 문서: 슈얼리 오브제 TRF 분석기 기술 문서와 accessory로 통합 필요 여부

**제조 공정 변경 범위**
- 기존 공정 유지 가능: [예/아니오]
- 변경 필요 공정: [없음 / 소재 교체 / 레이어 추가 / 신규 설비]
- 예상 단가 영향: [±N%]

**구현 난이도:** ★☆☆☆☆ ~ ★★★★★ ([이유])

**MVP 첫 스텝**
3개월 내 할 수 있는 가장 작은 벤치 실험:
→ [실험 명칭]: [실험 방법] → [성공 기준: CV% X% 이내]
```

## Phase 5 — 로컬 저장 + 최종 보고

### 저장 규칙

저장 경로:
```
./ideation_output/YYYYMMDD_stick_<슬러그>.md
```
- 날짜: 오늘 날짜 ISO 형식 (예: 20260227)
- 슬러그: 주제 영문 변환, 영문/숫자/하이픈만 (예: `urine-dipping-strip`)
- 저장 내용: Phase 1~4 전체 마크다운 (요약본 아님)

### 최종 요약 출력

```
## 최종 보고 — 스틱/스트립 정량 아이디어

| 항목 | 내용 |
|---|---|
| 주제 | $ARGUMENTS |
| 실행일 | YYYY-MM-DD |
| 총 생성 아이디어 | N개 |
| 채점 특화 기준 | 정량임팩트(30%)/실현성(25%)/규제(20%)/차별성(15%)/TRF호환(10%) |
| 최고 점수 아이디어 | [이름] — X.XX점 |
| 저장 위치 | ./ideation_output/YYYYMMDD_stick_<슬러그>.md |
| 권장 벤치 실험 | [TOP 1 MVP 스텝 한 줄 요약] |
| 예상 규제 클래스 | TOP 1 기준 Class [A/B] (Rule [번호]) |
```

## 실행 규칙

- 모든 출력은 **한국어** (소재명·기술용어 영문 병기 허용)
- 점수에 반드시 근거 한 줄 명시
- IVDR 분류 시 Rule 번호 + 소재 ISO 번호 반드시 포함
- MVP 스텝은 구체적 실험 조건 명시 (부피·횟수·성공 기준 포함)
- TRF 간섭 가능성이 있는 소재는 반드시 리스크로 명시
- 저장 파일은 Phase 1~4 전체 내용 포함 (요약 버전 금지)
