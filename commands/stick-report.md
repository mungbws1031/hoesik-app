$ARGUMENTS 주제로 스틱 아이디어 Phase 3–5를 실행해.

> **인수가 없을 경우:** 대화 맥락에서 가장 최근에 실행된 `/stick-generate` 또는
> `/ideation-generate-stick`의 주제를 자동으로 사용해.
> 주제를 특정할 수 없으면 "주제를 입력해 주세요. 예: `/stick-report 정량 스틱 사용편의성`" 안내.

대화 맥락의 Phase 2 스틱 아이디어 목록을 가져와 Phase 3 → 4 → 5를 실행해.

## Phase 3 — 가중치 매트릭스 점수화 → TOP 5

| 기준 | 가중치 | 판단 기준 |
|---|---|---|
| 정량 정확도 임팩트 | 30% | CV% 개선 정도 (±5% 이내 = 5점) |
| 구현 실현성 | 25% | 공정 변경 없이 적용 = 5점, 신규 소재 개발 = 2점 |
| IVDR/규제 용이성 | 20% | Class A = 5점, ISO 10993 필요 = 3점, Class B+ = 1점 |
| 차별성 | 15% | 경쟁사(Mira·Oova·Inito) 대비 독창성 |
| TRF 호환성 | 10% | TRF 간섭 없음 = 5점 |

동점 시: 정량 정확도 → TRF 호환성 → 구현 실현성 순 우선

## Phase 4 — TOP 5 구체화 템플릿
각 아이디어에 대해:
- 타겟 유저 (페르소나·채취 빈도·문제·기대 변화)
- 스틱 구조 상세 (소재 / 정량 메커니즘 / 목표 부피 / TRF 보호 방식)
- 핵심 기능 3가지 (물리 메커니즘 명시)
- 경쟁사 대비 차별점 (Mira·Oova 각각)
- IVDR 체크 (Class·Rule 번호·ISO 번호·기술 문서)
- 제조 공정 변경 범위 (유지 여부·변경 항목·단가 영향)
- 구현 난이도 ★~★★★★★
- MVP 첫 스텝 (실험명·방법·성공 기준 CV%)

## Phase 5 — 저장
경로: `./ideation_output/YYYYMMDD_stick_<슬러그>.md`
저장 후 최종 요약 테이블 출력.

## 실행 규칙
- 한국어 출력
- 점수에 근거 한 줄 필수
- IVDR Rule 번호 + ISO 번호 필수
- MVP는 구체적 실험 조건 명시
- TRF 간섭 소재 리스크 명시
