# Phase 2 (스틱 특화) — 18개+ 원석 아이디어 생성

**주제:** $ARGUMENTS

`/ideation-research-stick` 결과(또는 대화 맥락의 스틱 리서치 인사이트)를 바탕으로,
**딥핑 스틱/스트립의 소재·구조·정량 메커니즘**에 집중해 6가지 방법론으로 아이디어를 생성해.
**총 18개 미만이면 완료하지 말 것.**

---

## 방법론 1: SCAMPER (7개)

딥핑 스틱/스트립 관점에서 각 글자마다 1개:

- **S**ubstitute — 현재 흡수 패드 소재(예: nitrocellulose)를 다른 소재로 대체하면?
- **C**ombine — 스트립 + 다른 기능(정량 지시·밀봉·전처리)을 하나로 합치면?
- **A**dapt — 다른 IVD 기기(혈당 란셋, PCR 스왑, 임신 테스트기)의 스틱 구조를 가져오면?
- **M**odify/Magnify — 흡수 팁 크기·두께·표면적을 극단적으로 변경하면?
- **P**ut to other uses — 스트립을 딥핑 외 다른 채취 방식(위킹, 스프레이, 패드)에 쓰면?
- **E**liminate — 딥핑 단계 자체를 없애고 스트립이 직접 소변에 노출되게 하면?
- **R**everse/Rearrange — 소변을 스트립에 담그는 대신 스트립을 소변 위에 올려두면?

## 방법론 2: HMW (How Might We) (3개)

스틱/스트립 페인포인트 기반으로:
"우리는 어떻게 하면 [스틱 관련 페인포인트]를 [유저]를 위해 해결할 수 있을까?"
→ 질문 3개 작성 후 각 질문에 스트립 구조·소재 관련 아이디어 1개 이상 도출

## 방법론 3: JTBD (Jobs-to-be-Done) (3개)

유저가 스틱을 "고용"하는 진짜 이유:
- **Functional Job:** "정확한 부피를 실수 없이 채취하고 싶다" → 스트립 구조 아이디어
- **Emotional Job:** "채취 과정이 위생적이고 깔끔하게 느껴지고 싶다" → 스트립 디자인 아이디어
- **Social Job:** "전문적인 검사를 스스로 해낸다는 자신감을 갖고 싶다" → 스트립 UX 아이디어

## 방법론 4: 아날로지 (Analogy Thinking) (3개)

스틱/스트립 정량 문제를 다른 산업의 유사 솔루션으로 해결:
권장 대상 산업:
- **의료기기:** 혈당 란셋, PCR 비인두 스왑, 임신 테스트 위크
- **식품:** 바리스타 에스프레소 도징, 식품 수분 측정 스트립
- **공업:** 리트머스 pH 스트립, 수질 측정 딥스틱, 도료 두께 게이지

"[산업]에서는 정량/정밀 접촉 문제를 [방법]으로 풀었다 → 슈얼리 스트립에 적용하면 [아이디어]"

## 방법론 5: 극단적 유저 (Extreme User) (3개)

스틱 사용 관점의 극단 유저:
- **파워 유저:** 하루 2회 측정하는 IVF 시술 중 여성 → 스트립 구조에서 무엇을 원할까?
- **비사용자:** "소변 스틱 만지기 싫어서 안 쓴다" → 스트립 설계로 접촉을 최소화하려면?
- **접근성 유저:** 손 떨림이 있는 고령 갱년기 여성 → 스트립 형태·그립이 어떻게 바뀌어야 하나?

## 방법론 6: 미래 역산 (Backcasting from 2030) (3개)

"2030년의 이상적인 딥핑 스틱은 어떤 모습인가? 거기서 역산해."
- 미래 상태 1문장 (예: "2030년엔 스트립이 변기 물에 자동 반응해 정량 채취")
- 현재 시작점 아이디어 1개
→ 3세트 작성

## 실행 규칙

- 모든 출력은 **한국어** (소재명·기술용어 영문 병기 허용)
- 반드시 18개 이상 생성 — 부족하면 방법론 추가 반복
- 각 아이디어에 **스트립/스틱의 물리적 메커니즘** 명시 (추상적 표현 금지)
- TRF 4-호르몬 분석 호환성 항상 고려
- IVDR Rule 5 (Class A accessory) 컨텍스트 유지
- SuGenTech 브랜드: SU Red #E60044, 프리미엄 femtech 포지셔닝 반영
- 결과는 `./ideation_output/generate-stick_<날짜>_<슬러그>.md`에 저장
