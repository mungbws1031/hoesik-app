# Phase 1 — 웹 리서치: 현실 파악

**주제:** $ARGUMENTS

다음 3가지를 웹 검색으로 조사해. 각 항목마다 검색을 별도로 실행할 것.

## 검색 1: 유저 페인포인트
키워드: "$ARGUMENTS pain points user complaints 불편함 문제점"
- 실제 사용자 리뷰, 커뮤니티 글, 연구 논문에서 불편함 수집
- 최소 5개 구체적 페인포인트 도출

## 검색 2: 트렌드
키워드: "$ARGUMENTS femtech medtech trend 2025 2026 innovation"
- 최근 12개월 내 관련 기술·시장·UX 트렌드
- 학술 자료, 업계 보고서, 뉴스 포함

## 검색 3: 경쟁사 갭
키워드: "$ARGUMENTS competitor review gap weakness alternative"
- 주요 경쟁 제품·서비스의 약점, 리뷰 평점 낮은 항목
- 해결 못한 문제 명시

## 출력 형식

```
### Phase 1 결과 — "$ARGUMENTS"

#### 페인포인트 (5개+)
1. ...
2. ...

#### 트렌드 (3개+)
| 트렌드 | 출처 | 핵심 내용 |
|---|---|---|
| ... | ... | ... |

#### 경쟁사 갭
| 경쟁사 | 약점 | 기회 |
|---|---|---|
| ... | ... | ... |

#### 리서치 요약 인사이트
→ Phase 2 아이디어 생성에 활용할 핵심 방향 3줄 요약
```

## 실행 규칙
- 모든 출력은 **한국어**
- 출처(URL) 반드시 명시
- 추측 금지 — 검색 결과 기반 사실만 기재
- Phase 1 결과는 `./ideation_output/research_<날짜>_<슬러그>.md`에 저장
  - 슬러그: 영문/숫자/하이픈만 사용
