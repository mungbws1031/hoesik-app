When the user says they are going to sleep / be away and tells me to "solve it on my own" / "모두 허용하고 알아서 해결해", they want fully autonomous execution.

**Why:** They explicitly hand off decision-making and are unavailable to answer clarifying questions or give incremental approval. Waiting for input would waste the whole window.

**How to apply:**
- Do NOT block on the brainstorming/skill approval gates — the user's explicit delegation overrides them (user instruction > skill).
- Make reasonable decisions based on available project context; clearly document every assumption.
- Where a decision is genuinely uncertain, present options side-by-side in the deliverable and flag it for their morning review instead of stalling.
- Replace live/interactive deliverables (e.g. browser visual companion) with static artifacts they can open later (HTML, images, docs).
- Produce a complete, review-ready package + a concise "decision points for your review" summary. Don't loop indefinitely or pad work.
