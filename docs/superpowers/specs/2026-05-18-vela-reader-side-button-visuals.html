측면 버튼 구조 탐색

스마트폰 사이드 버튼 감성의 물리 버튼 — 4가지 구조 컨셉 · 단면도 · 비교 · 권장안 (2026-05-18, 야간 자율 작업)

1. 디바이스 컨텍스트 & 제약

Vela Reader는 달걀형 프리미엄 호르몬 측정 기기다. 매끈한 백색 사출 플라스틱 바디 + 로즈골드 적도 액센트 밴드, 상단 다크 윈도우, 하단 INSERT 스트립 슬롯. 현재 외형엔 버튼이 없다. 측면에 단일 다기능 버튼을 추가한다.

핵심 제약

  • 위생/세척성 — 소변 컵에 담근 스트립을 다루는 펨테크 기기. 표면을 닦아낼 수 있어야 하고, 액체가 고이는 틈을 최소화해야 함.
  • 프리미엄 심리스 외형 — 매끈한 유기적 폼을 깨지 않을 것. 로즈골드 밴드를 디자인 언어로 활용.
  • 무광시 촉각 조작 — 보지 않고도(컵 위에서) 찾고 누를 수 있어야 함.
  • 단일 버튼 다기능 — 짧게/길게/더블 프레스. UX 단순.
  • 저비용·소형·배터리 — 사출 플라스틱, 내부 공간/배터리 제약.

추정 기능 매핑 (가정)

  • 짧게 — 깨우기 / 측정 시작 확인
  • 길게 2초 — 전원 ON/OFF
  • 길게 6초 — BLE 페어링 / 리셋
  • 더블 — 즉시 동기화 (선택)

※ 기능 매핑은 가정이며, 아침 검토 시 확정 필요.

2. 버튼 구조 컨셉 (단면도)

각 단면도: 좌측이 기기 외부, 우측이 내부. 회색=쉘, 금색=손가락 접촉면, 청록=작동 메커니즘, 점선=실링.

컨셉 A · 저비용 폴백

경질 키캡 + 메탈 돔

고전적 스마트폰 사이드 버튼

  • 친숙한 크리스프 클릭, 최저 비용, 검증된 양산성
  • 로즈골드 마감 키캡으로 밴드와 연결 가능
  • 둘레 틈 → 침투/오염 경로, 세척성 약함
  • 내부 부트/O링 별도 실링 필요
컨셉 B · 권장

일체형 실리콘 오버레이 + 내부 돔

실드 멤브레인 (방수 의료기기 표준)

  • 완전 실드(IP67+), 틈 없음 → 완벽한 닦임 — 위생 컨텍스트 최적
  • 내부 메탈 돔으로 진짜 클릭감 유지, 수백만 사이클 내구
  • 저비용·소형, 검증된 방수 의료기기 표준 구조
  • 경질 키캡 대비 약간 부드러운 타격감 (튜닝으로 보완)
컨셉 C · v2 미래

솔리드스테이트 압력 존 + 햅틱

iPhone 액션 버튼 방식

  • 침투 경로 0, 최상의 심리스 외형 (Apple 2027 방향)
  • 기계적 마모 없음
  • 최고 비용·복잡도 (센서+드라이버+액추에이터+튜닝)
  • 전원 OFF 상태 콜드스타트 문제 — 완전 종료 시 누름 감지 불가
  • 배터리·내부 공간 부담 ↑
컨셉 D · 대안

리세스 필 버튼 + 내부 실리콘 부트

경질 클릭감 + 실드 하이브리드

  • 경질 클릭감 + 실드 + 오작동 저항(리세스)
  • 로즈골드 베젤 링으로 브랜드 연속성
  • 리세스에 잔여물 고일 수 있음
  • 젖은/장갑 손가락 작동성 ↓, 부품 수 ↑

4. 권장안 — 컨셉 B

일체형 실리콘 오버레이 버튼 + 내부 메탈 돔을 1순위로 권장한다. 위생·실링·실제 클릭감·저비용·검증된 신뢰성을 동시에 만족하는 유일한 안이며, 로즈골드 밴드 안의 의도적 액센트로 스타일링할 수 있다.

배치
로즈골드 적도 밴드 위, 자연 그립 시 엄지 도달 15~20mm (20mm 아크 룰). 단일 버튼.
형상
작동면 Ø8~10mm, 0.3~0.5mm 볼록 → 무광시 촉지 가능. 중앙 리프 엠보스로 방향 인지.
작동력/스트로크
약 2.5~4 N, 체감 스트로크 0.3~0.5mm (내부 메탈 돔 250~350gf, 0.25mm 붕괴) — 인체공학 범위 내, 오작동 저항.
실링
실리콘 오버레이 오버몰드 또는 3M 467MP급 접착 + 내부 리브 글랜드 → IP67 목표.
피드백
메탈 돔 기계적 클릭(≥300k 사이클) + 화면/LED 확인 + 앱 BLE 햅틱(기기 아닌 폰).
소재
스킨 매칭 LSR 실리콘 오버레이, 선택적 로즈골드 PVD 링 베젤; SS301 메탈 돔; FPC 접점.

아침 검토용 결정 포인트

  • 기능 매핑 확정 — 짧게/길게/더블 프레스 동작 (현재 가정값).
  • 컨셉 B vs D — 심리스 위생(B) vs 더 단단한 경질 클릭감(D) 중 우선순위.
  • 로즈골드 PVD 베젤 링 적용 여부 (브랜드 연속성 ↔ 비용/세척성).
  • 버튼 위치 — 좌/우 측면, 상단 윈도우 기준 정확한 좌표는 기구 도면 필요.
  • IP 등급 목표 — IP67 충분한지, 침수 세척(IP68/IP69K) 필요한지.
