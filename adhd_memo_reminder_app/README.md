# ADHD 메모 및 알림 앱

표준 라이브러리만 쓰는 로컬용 `tkinter` 데스크톱 앱입니다.

## 들어있는 기능

- 빠른 한 줄 캡처
- `Main / Ref / Park` 분리
- 시간 또는 날짜 기반 알림
- `5분 / 15분 / 30분 / 내일` 스누즈
- `+15분 체크포인트` 버튼
- JSON 자동 저장

## 실행

Windows에서 가장 쉬운 방법:

```bat
run_app.bat
```

같은 폴더의 `run_app.ps1`이 실제 실행 경로를 고르고, `run_app.bat`는 그 스크립트를 호출합니다.

직접 실행할 수도 있습니다.

```bat
python app.py
```

`run_app.bat`는 먼저 설치된 일반 Python을 찾고, 없으면 Codex 번들 Python을 사용합니다.
GUI가 안 뜨는 환경에서는 자동으로 CLI 모드로 내려갑니다.

## 입력 규칙

- 알림 입력 예시: `18:30`
- 알림 입력 예시: `2026-04-22 18:30`
- `Main`은 지금 할 것 1~3개 정도로 유지하는 쪽이 좋습니다.
- 떠오른 생각을 바로 버리지 말고 `Park`에 넣어 둔 뒤 나중에 다시 보면 됩니다.

## 저장 파일

앱 데이터는 같은 폴더의 `app_state.json`에 저장됩니다.
