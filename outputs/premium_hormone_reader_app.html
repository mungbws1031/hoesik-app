Vela Flow

조용하고 정확하게, 오늘의 변화를 읽는 동반 앱.

매트 화이트 리더기와 같은 재질 감각을 앱 안으로 옮겼습니다. 결과를 과장하지 않고, 지금 상태와 다음 행동만 차분하게 보여주는 프리미엄 여성호르몬 리더기 동반 화면 설계입니다.

Mobile portrait only
Reader sync flow
Trend-first, not diagnosis
Visual Thesis Matte white surfaces, black glass result panels, one rose-gold accent.
Interaction Thesis Pair pulse, result reveal, stable trend scroll with no decorative noise.

Core Flow

첫 사용자 흐름은 기기 연결에서 시작해 검사 가이드, 결과 해석, 누적 추적까지 한 번에 이어집니다.

1

Pair

리더기 연결과 데이터 성격 안내를 먼저 보여줍니다.

2

Start

홈에서 최근 상태와 다음 검사를 바로 이해합니다.

3

Dip

dip, carry, insert, wait 단계를 큰 타이포로 안내합니다.

4

Sync

결과 도착과 지연, 재시도 여부를 상태 기반으로 처리합니다.

5

Coach

상태 설명 다음에 행동 하나만 제안합니다.

6

Track

cycle day 축에서 최근 변화를 조용하게 비교합니다.

State Review

테스트 플랜의 네 가지 예외 상태를 포함해, 모든 화면이 동일한 데이터 계약 안에서 움직이도록 구성했습니다.

Screen Set

온보딩과 검사 가이드는 별도 플로우로, 홈·트렌드·코치는 하단 탭 구조로 유지했습니다.

1. Onboarding / PairingFlow entry
2. HomeHome tab
3. Step GuideFlow support
4. Result & CoachCoach tab
5. Trend / CalendarTrend tab

Rules And Contract

카피는 감정 유도보다 운영 가능한 문장으로, 데이터는 특정 호르몬 패널이 고정되지 않도록 타입 중심으로 유지합니다.

Status, meaning, next action

모든 핵심 문장은 상태를 먼저 말하고, 그 의미를 짧게 설명한 뒤, 다음 행동 하나를 제안합니다.

Trend reference only

결과 화면과 코칭 화면 모두 의학적 확정처럼 읽히지 않도록 caution copy를 항상 유지합니다.

State is product-owned

미연결, 동기화 지연, 불완전 검사, 주기 데이터 없음은 모두 시스템 상태로 표현하고 사용자 탓으로 쓰지 않습니다.

Low-noise premium UI

큰 타이포, 얇은 디바이더, 블랙 글래스 결과 패널, 하나의 로즈골드 포인트만 사용합니다.
