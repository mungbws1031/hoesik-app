## LFA 방식 진단 테스터스틱 120μL 소변 정량 수집 — 범부서 토론 종합 결론

---

## 합의 사항

### 1. "20가지 방법 나열"은 전 팀 만장일치로 기각
| 합의 근거 | 관련 팀 |
|---|---|
| 솔루션 과잉 → 사용자 세그먼트별 최적 1~2개로 수렴해야 함 | 기획 |
| 20가지 노출은 인지 과부하·의사결정 마비·오류율 상승 초래 | 디자인 |
| 기술개발 ≠ 사업화 성공, 나열보다 규제경로 확정이 선행 | 전략기획 |
| 수집 난이도가 실제 구매 장벽인지 미검증 | 시장조사 |
| 방법 결정은 R&D/임상팀 소관, SW·QA는 검증 역할 | 개발·QA |

> **결론:** 기술 후보 다수 탐색(20가지)은 R&D 내부 워크시트로만 유지하고, 사업화 트랙에서는 규제·시장·사용성 기준으로 **최종 1~2개 방식만 선별**한다.

### 2. 글로벌 규제경로 우선 확정 — 전 팀 동의
- **CE 마크 (12~18개월) 우선 추진**
- **미국 FDA 510(k) 병렬 추진**
- **국내 식약처는 CE/510(k) 획득 후 자동 진입 시나리오 (총 ~24개월)**
- 규제경로 확정이 기술스펙·UX·마케팅·품질게이트 등 **모든 병렬 작업의 기준점**임을 전 팀 재확인

### 3. 킥오프 회의(2주 내) 개최 및 아젠다 확정

| 순서 | 안건 | 주관/핵심 참여 |
|---|---|---|
| ① | 규제경로 확정 + 품질게이트 동시 확정 | 전략기획 · QA |
| ② | API 스펙 (데이터 포맷·오류허용범위·임계값) | 개발 · 하드웨어/R&D |
| ③ | 시장별 UX 플로우 프로토타입 검토 | 디자인 |
| ④ | 세그먼트 × 규제시장 페인포인트 매트릭스 → 기술선별 기준 | 기획 · 시장조사 |
| ⑤ | 마케팅 포지셔닝 정렬 | 마케팅 |

### 4. 품질게이트 기준 전 팀 수용
- **정량 편차: ±10% 이내**
- **반복 재현성: n ≥ 30**
- **온·습도 환경 변수 커버**
- **데이터 보안 무결성 확보**
- CE·510(k) 각 규제별로 별도 기준표 수립
