## 핵심 합의 사항

### 1. 딥스틱 단일 메커니즘만으로는 사업화 불가 — 양 팀 합의 완료

마케팅팀은 재테스트율 15% 시 CPA 17,250원으로 마진 임계값 초과를 제시했고, 제품설계팀은 딥 깊이 단독 의존 시 ±15% 편차로 의료기기 ±5% 요구를 충족 불가함을 검증 데이터(David, N=42)로 뒷받침했다. **기술적 한계가 곧 마케팅 ROI 붕괴로 직결된다는 인과 구조에 양 팀 이견이 없다.** 따라서 단일 메커니즘 출시는 배제한다.

### 2. B안(스토퍼+시각 피드백+진동 모듈)이 유일한 사업화 후보 — 양 팀 합의 완료

| 구분 | A안 | B안 |
|------|-----|-----|
| 단가 증분 | 0원 | +450원 |
| 예측 재테스트율 | ~9% | ~4% |
| CPA 영향 | 16,350원 (임계선 초과) | 15,600원 (마진 내) |

마케팅팀이 제시한 **CPA 임계선 = 재테스트율 8%** 기준에서 A안(9%)은 미달, B안(4%)만 통과한다. 제품설계팀도 A안의 사업화 기준 미달 판정을 수용했다. **B안을 사업화 1순위 설계 방향으로 확정한다.**

### 3. 멀티모달 피드백은 UX 옵션이 아닌 CAC 방어 장치 — 양 팀 합의 완료

Mia IDEO 데이터(N=347)에서 피드백 부재 시 재딥 오류율 23% → 피드백 추가 시 4%로 감소. 마케팅팀이 이를 "피드백 = CAC 방어 장치"로 재정의했고 제품설계팀이 수용했다. **피드백 레이어는 비용 항목이 아니라 마진 방어 투자로 회계적으로도 분류해야 한다.**

### 4. 수치 기반 의사결정 원칙 — 양 팀 합의 완료

김도연 팀장의 "숫자 없이 착수 불가" 원칙과 David Kang 팀장의 "숫자 없이 진행되는 의사결정은 허용하지 않겠다"는 선언이 정확히 일치한다. **모든 후속 의사결정은 정량 데이터 선행 → 임계값 공동 설정 → 실행의 3단계 프로토콜을 따른다.**

## 주요 이견 및 조율 방안

### 이견 1: 내부 검증 데이터(N=42)의 현장 신뢰도

**마케팅팀 입장:** N=42는 실험실 편향이 포함된 수치이며, 실사용 환경(조명·각도·사용자 숙련도)에서 재테스트율 4%가 유지된다는 보장이 없다. 광고 유입 코호트 30명 필드 파일럿을 통해 실험실-현장 격차를 먼저 측정해야 한다.

**제품설계팀 입장:** 필드 파일럿 전에 딥 속도 극단값(1.2mm/s, 7.8mm/s) 스트레스 테스트 데이터를 먼저 제출하여, 프로토타입이 실사용 변수를 구조적으로 흡수하고 있음을 증명하겠다. 스트레스 테스트 통과 후 필드 파일럿 진행이 순서다.

**조율 방안:** 양 팀 주장 모두 타당하며 순서의 문제다. **스트레스 테스트 → 스트레스 테스트 통과 확인 → 필드 파일럿의 2단계 검증 프로토콜**을 채택한다.

- **1단계(Week 1~2):** 제품설계팀이 B안 프로토타입의 딥 속도 극단값 스트레스 테스트 실시. 통과 기준은 전 구간 ±5% 이내.
- **2단계(Week 3~4):** 스트레스 테스트 통과 시, 마케팅팀이 설계한 광고 유입 코호트 30명 대상 필드 파일럿 실시. 측정 항목: 실사용 재테스트율, 재딥 오류율, 사용자 종료점 인지 여부.
- **게이트 조건:** 스트레스 테스트 미통과(±5% 초과) 시 필드 파일럿 미진행, 설계 보정 후 재검증.

### 이견 2: A안의 완전 폐기 vs 별도 SKU 분리

**마케팅팀 입장:** A안(재테스트율 9%)은 CPA 임계선 초과이므로 사업화 대상에서 제외.

**제품설계팀 입장:** A안은 원가 제약 시장(신흥국 채널)을 위한 별도 SKU로 분리 검토 가능. 하나의 설계가 모든 시장을 커버하려는 것이 오히려 설계 오류다.

**조율 방안:** A안을 즉시 폐기하지 않되, **현 시점에서 리소스를 분산하지 않는다.** B안의 사업화 검증(필드 파일럿 완료 + Break-even 확정) 이후, A안의 신흥국 시장 적합성을 별도 프로젝트로 검토한다. 이 결정의 근거는 다음과 같다:

- 현재 팀 리소스(프로토타입 제작·금형·파일럿 운영)가 한정적이며 B안에 집중해야 한다.
- A안의 9% 재테스트율이 신흥국 시장에서 수용 가능한지 여부는 해당 시장의 가격 탄력성·경쟁 제품 정확도·규제 기준에 따라 달라지므로 별도 시장 분석이 필요하다.
- B안 양산 확정 후 A안은 진동 모듈만 제거한 파생 SKU이므로 추가 설계 비용이 최소화된다.

### 이견 3: 코호트 LTV 분석 기준과 이탈 원인 인과 관계

**마케팅팀 입장:** 기존 고객 1,000명을 재테스트 필요군 vs 완벽 결과군으로 분류하여 Month-6 LTV 격차 50% 이상이면 PMF 부재로 판정. 이탈 원인이 기술적 부족인지 콘텐츠 부족인지를 구분해야 투자 방향이 결정된다.

**제품설계팀 입장:** 코호트 분류 기준인 "정확도 임계값(85% vs 90%)"이 합의되지 않으면 시뮬레이션 자체가 무의미하다. 기술 정확도 데이터 공유가 선행되어야 한다.

**조율 방안:** 다음 기준으로 확정한다.

- **정확도 임계값:** B안 스트레스 테스트 결과의 실측 편차를 기준으로 설정. 예를 들어 스트레스 테스트에서 ±4.8% 확인 시, "정확도 95.2% 이상 = 완벽 결과군", "95.2% 미만 = 재테스트 필요군"으로 분류.
- **이탈 원인 구분:** 필드 파일럿 30명에게 재테스트 발생 시 즉시 설문(3문항 이내)을 실시하여 "결과를 믿을 수 없어서(신뢰 문제)" vs "결과가 나왔는지 확인이 안 돼서(종료점 인지 문제)" vs "색이 이상해서(기술 정확도 문제)"를 분류한다.
- **판정 기준:** 기술 정확도 문제가 전체 이탈의 50% 이상이면 설계 보정 우선, 신뢰/종료점 문제가 50% 이상이면 콘텐츠+피드백 강화 우선.

## 최종 결정 및 근거

### 최종 결정: B안(스토퍼+시각+진동) 기반 2단계 검증 후 조건부 사업화

```
[Week 1~2] 스트레스 테스트 (제품설계팀 단독)
    ├── 통과(±5% 이내) → [Week 3~4] 필드 파일럿 (양 팀 공동)

    │       └── 재테스트율 >12% → B안
