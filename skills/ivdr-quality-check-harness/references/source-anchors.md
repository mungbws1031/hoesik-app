# Official Source Anchors

Use official sources first for source-sensitive IVDR facts. Record the checked date in every harness report when these facts matter.

## Source Freshness Rules

- If the user asks for classification, conformity route, transition timing, common specifications, harmonised standards, MDCG revision status, or legal interpretation, verify live official sources before giving a conclusion.
- If live verification is not possible, mark `Regulatory confirmation needed` and do not treat the fact as confirmed-current.
- Do not copy long legal passages into the answer. Summarize the anchor and link to the official source.
- Remember that MDCG guidance is guidance and not binding law; use it as a common implementation reference and still flag RA/legal/notified-body confirmation when decisions are material.
- Use the report date as `Checked date`, not the publication date. Also note the publication or revision date when visible.
